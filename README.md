# Persistencia-Tarea-1
El proyecto FoodPackingORM es una aplicación de escritorio en Java y Maven diseñada para gestionar el inventario de la empresa FOODPACKING mediante una arquitectura eficiente. Utiliza un mapeo objeto-relacional con Hibernate y JPA conectado a una base de datos MySQL para asegurar la persistencia de los datos. Además, integra una interfaz gráfica en Java Swing que facilita la ejecución de operaciones CRUD de forma interactiva y estructurada. Esta solución combina la robustez del backend empresarial con componentes visuales optimizados para el control logístico.
